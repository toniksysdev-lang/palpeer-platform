# Deploy Palpeer API on Render

Blueprint file: [`render.yaml`](../render.yaml) (API + Postgres + Redis).

## 1. Create the Blueprint

1. Open [Render Dashboard](https://dashboard.render.com/) → **New** → **Blueprint**.
2. Connect GitHub and select **`toniksysdev-lang/palpeer-platform`**.
3. Confirm `render.yaml` is detected → **Apply**.
4. When prompted for `sync: false` variables, fill at least:

| Variable | Example / notes |
|----------|-----------------|
| `CORS_ALLOWED_ORIGINS` | `https://admin.yourdomain.com,http://localhost:5173` |
| `PALPEER_SMTP_HOST` | Your SMTP host |
| `PALPEER_SMTP_PORT` | `587` |
| `PALPEER_SMTP_USERNAME` | SMTP user |
| `PALPEER_SMTP_PASSWORD` | SMTP password |
| `PALPEER_SMTP_SSL` | `true` |
| `PALPEER_MAIL_FROM` | `noreply@yourdomain.com` |
| `PALPEER_MAIL_FROM_NAME` | `PALPEER` |
| `PALPEER_MAIL_HEADER_FROM` | same as from (optional) |
| `ADMIN_BOOTSTRAP_EMAIL` | First admin user email (optional) |
| `GOOGLE_CLIENT_IDS` | Comma-separated OAuth client IDs, or leave empty |

`JWT_SECRET` is generated by Render. Postgres/Redis are wired automatically.

## 2. Plans

- **Web (`palpeer-api`)**: `starter` — Java Docker builds need more RAM than free.
- **Postgres (`palpeer-db`)**: `basic-256mb` (adjust in `render.yaml` if needed).
- **Redis (`palpeer-redis`)**: `starter`, private network only.

## 3. After deploy

- Health: `https://<service>.onrender.com/actuator/health`
- API base: `https://<service>.onrender.com/api/v1`
- WebSocket: `https://<service>.onrender.com/ws` (SockJS) / `wss://…/ws/websocket`

Point admin (`VITE_API_BASE_URL`) and mobile (`EXPO_PUBLIC_API_BASE_URL`) at that HTTPS API URL.

## 4. Custom domain (optional)

In the web service → **Settings** → **Custom Domains** → add `api.yourdomain.com` and follow DNS instructions.

## 5. Local Docker still works

`docker-compose.yml` overrides profile/host for local Postgres/Redis. Dockerfile default is `prod`; compose sets `SPRING_PROFILES_ACTIVE=dev`.
